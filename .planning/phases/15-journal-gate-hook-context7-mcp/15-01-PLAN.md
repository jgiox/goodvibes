# Plan 15-01: Journal-gate hook and context7 `.mcp.json`

## Objective

Ship a Claude Code `PreToolUse` hook that blocks `git commit` unless `JOURNAL.md` is staged, and a
project-scoped `.mcp.json` wiring context7 at its keyless public endpoint. Both flow through the
existing generic copy/manifest pipeline, so no CLI code changes are needed.

## Assumptions

- Requirement HOOK-01 ("inline shell command, no separate script file") overrides the research
  suggestion of a `.mjs`/`.sh` script. Inline POSIX `sh` avoids `jq`, Node, and the wheel exec-bit question.
- Claude Code hook docs (code.claude.com/docs/en/hooks, fetched 2026-09-24): shell form runs under
  `sh -c` on macOS/Linux and Git Bash on Windows (PowerShell only if Git Bash is absent); `if` uses
  permission-rule syntax and checks each subcommand of a compound command; exit 2 blocks and stderr
  becomes the reason; `CLAUDE_PROJECT_DIR` is exported.
- context7 README (upstash/context7, fetched 2026-09-24): endpoint `https://mcp.context7.com/mcp`;
  "API Key Recommended ... for higher rate limits" (keyless works); key header is `Authorization: Bearer`.
- Claude Code MCP docs: `${VAR}` expansion is supported in `headers`; interactive sessions prompt
  once to approve project `.mcp.json` servers; `claude mcp reset-project-choices` resets the choice.

## Tasks

1. Add `hooks.PreToolUse` (`matcher: "Bash"`, `if: "Bash(git commit*)"`, inline `command`) to
   `templates/.claude/settings.json`, keeping `permissions` intact. Gate logic, in order:
   - exit 0 unless stdin mentions `git commit` (defence if an older Claude Code ignores `if`)
   - exit 0 if not a git repo, if `HEAD` does not exist (first commit), if `MERGE_HEAD`,
     `rebase-merge` or `rebase-apply` exists in the git dir, or if the command has `--amend`
   - exit 0 if `JOURNAL.md` is staged (`git diff --cached --quiet -- JOURNAL.md` fails)
   - if the command also stages (`git add`, `-a`, `--all`), exit 0 when `JOURNAL.md` differs from
     `HEAD` in the working tree or is untracked
   - otherwise print what is missing and the fix to stderr, exit 2
2. Add `templates/.mcp.json` with `context7: {type: "http", url: "https://mcp.context7.com/mcp"}`.
3. Integration tests (`packages/npm/src/journal-gate.integration.test.ts`): run the shipped command
   string under real `sh` against temp git repos, one test per edge case; assert `.mcp.json` shape
   and absence of any key. Add copy-templates assertions for fresh init and `--minimal`.
4. Docs: onboarding "Claude Code extras" section (hook scope, exemptions, opt-out, trust prompt,
   optional `${CONTEXT7_API_KEY}` upgrade, never commit a literal key); README items 6 and 7; CHANGELOG.

## Risks

- Windows without Git Bash runs hooks in PowerShell; the `sh` syntax then errors, which Claude Code
  treats as non-blocking, so the gate fails open. Documented, not fixable without Node or a second shell variant.
- `if` matching is best-effort; `git -C dir commit` or `$VAR`-built commands can slip past.
- Existing `.claude/settings.json` is not overwritten by `init`; delivery to existing projects is Phase 16.
