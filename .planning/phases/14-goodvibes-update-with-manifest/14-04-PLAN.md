    update.ts exports registerUpdateCommand(program: Command): void.
    Command name: 'update'. Options: --dry-run (dryRun boolean), --force (force boolean).
    Flow:
    1. intro('goodvibes update')
    2. readManifest(cwd) → if null: note(UPD-05 message, 'No manifest'), outro('Nothing updated.'), return (exit 0 — no process.exit(1))
    3. resolveTemplatesDir() → templateDir
    4. detectProjectType(cwd) → projectType (for CI variant mapping and applying)
    5. categorise(templateDir, cwd, manifest) → { overwrite, skip, netNew } (see categorise logic below)
    6. if dryRun: note(3-category summary string, 'Dry run — no files written'), outro('Run without --dry-run to apply.'), return
    7. if !force && overwrite.length > 0: const proceed = await confirm({message: `Overwrite ${overwrite.length} managed file(s)?`}); if isCancel(proceed) || !proceed: cancel('Update cancelled.'), process.exit(0)
    8. Apply changes: for each rel in [...overwrite, ...netNew]:
       - resolve templateSrc: if rel === 'CLAUDE.md' → join(templateDir, 'CLAUDE.md'); if rel === '.github/workflows/ci.yml' → join(templateDir, '.github/workflows/ci-' + projectType + '.yml'); else → join(templateDir, rel)
       - if !existsSync(templateSrc): skip (template no longer has this file)
       - if rel === 'CLAUDE.md': read templateSrc as utf-8, call await mergeClaude(join(cwd, rel), templateContent)
       - else: use copy(templateSrc, join(cwd, rel), {overwrite: true}) from fs-extra
    9. writeManifest(cwd, [...overwrite, ...netNew].filter(rel => existsSync(join(cwd, rel))), getVersion())
    10. note(summary of applied changes, 'Update complete'), outro('Done!')

    categorise(templateDir, cwd, manifest) internal async function:
    - allTemplateFiles = await listTemplateFiles(templateDir) — excludes non-selected CI variants via: for ci variant files, map to their dest name (the selected variant → 'ci.yml', others → skip)
    - Compute ciVariants = ['ci-node.yml', 'ci-python.yml', 'ci-both.yml'], selectedVariantSrc = 'ci-' + projectType + '.yml'
    - First pass over manifest.files keys: for each rel, check dest SHA vs manifest SHA → push to overwrite or skip
    - Second pass for net-new: for each template file in allTemplateFiles (skipping '.goodvibes.json' and non-selected ci variants), compute destRel (map selectedVariantSrc → 'ci.yml', others → same); if destRel not in manifest.files → push to netNew
    - Note: manifest.files keys are the source of truth for managed files; template files not in manifest are net-new

    Categorisation detail for manifest iteration (first pass):
    - for (const [rel, manifestSha] of Object.entries(manifest.files)):
      - destPath = join(cwd, rel)
      - if !existsSync(destPath): overwrite.push(rel) (dest gone, re-create)
      - else: destContent = await readFile(destPath, 'utf-8'); destSha = createHash('sha256').update(destContent, 'utf8').digest('hex'); if destSha === manifestSha: overwrite.push(rel); else: skip.push(rel)

    Net-new detection (second pass):
    - for each templateFile in allTemplateFiles: skip '.goodvibes.json'; for ci variants, if not selectedVariantSrc skip; compute destRel (selectedVariantSrc → 'ci.yml', else → templateFile); if !(destRel in manifest.files): netNew.push(destRel)
